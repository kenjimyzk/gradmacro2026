1   講義の目的
第 12 回では、第 11 回で学んだ TANK（Two-Agent New Keynesian）モデルを、学
部初級マクロの伝統的な 45 度線分析を現代的に再構築した「New Keynesian Cross
（NK クロス）」の枠組みとして読み直します。

第 11 回では、流動性制約家計（Type H）への移転給付 𝑧𝑡 を外生ショックとして扱い、その
将来への期待成長率 𝔼𝑡 Δ𝑧𝑡+1 が TANK 自然実質利子率 𝑟𝑡       をシフトさせる動学を考
                                     𝑓,𝑇

察しました。これに対し、本講義では 𝑧𝑡 を外生ショックとしてではなく、企業の集計純配
当 𝑑𝑡 に内生的に連動する「純配当移転ルール」

                       𝜆𝑧𝑡 = 𝜏𝐷 𝑑𝑡

によって決定されるものと定式化します。ここで 𝜆 は経済全体における Type H 家計の
人口比率です。また、𝜏𝐷 は企業の集計純配当の変動のうち Type H 家計への総移転へと
配分する割合を規定する一次近似上の制度的負荷係数です。したがって、Type H 家計一
人当たりに給付される実質移転は 𝑧𝑡 = (𝜏𝐷 /𝜆)𝑑𝑡 と表されます。

この定式化の変更により、外生的な移転の期待変動が自然利子率を動かすという第 11 回
の視点から、マクロ集計産出、企業の純配当、および家計への移転給付が互いに連動し合う
「所得分配の一般均衡フィードバック・ループ」へと分析の焦点が発展します。移転 𝑧𝑡 は
制度パラメータではなく内生的に決まる変数であり、その連動の強弱を規定するパラメー
タ 𝜏𝐷 こそが政策・制度係数です。この制度係数 𝜏𝐷 の違いが、計画支出曲線の傾きと実質
利子率に対する需要感応度を決定づけることになります。

本講義の中心的な眼目は、TANK モデルを 3 本の連立 NK 方程式体系として解くのでは
なく、「計画支出（Planned Expenditure: PE）曲線」と 45 度線の交点として図解し、
そのメカニズムを解明することにあります。家計の主観的割引因子 𝛽 が 1 に近く、期待の
持続性を表す閉鎖係数 𝑝 が 1 に近すぎない状況において、標準的な代表的家計（RANK）
モデルでは、現在所得の変動が消費に与える直接的な影響は極めて小さく、実質利子率ギャ
ップを通じた異時点間代替（直接効果）が需要変動のほぼ全てを占めます。

これに対し、流動性制約家計が存在する TANK モデルでは、Type H 家計が手元に入っ
た現在所得をすべて消費に回すため、標準的なパラメータ領域において、現在所得の変動が
消費を誘発する間接効果（所得フィードバック）が極めて強力に働きます。ただし、実質利

例えば、標準的なパラメータ較正（𝛽 = 0.99, 𝛾 = 𝜑 = 1, 𝜆 = 0.30, 𝑝 = 0, 𝜏𝐷 = 0）のも

ク）の増幅」という 2 つの相反する力を統合する核心的パラメータが、

    同一の選好パラメータ（𝛾, 𝑝）および同一の実質利子率ギャップの低下幅を比較する
    とき、通常符号領域 𝜆𝜒 < 1 のもとで「TANK モデルの産出反応が RANK モデル

    すること（𝜒 > 1 ⟺ 𝜏𝐷 < 𝜆）」は数学的に完全に同値である。

なお、この結論は「所与の実質利子率ギャップ経路に対する条件付きの総需要反応」を分析
したものであり、価格硬直性や中央銀行のテイラー・ルールを連立させた完全均衡におけ

本講義の本編では、純配当移転ルールからパラメータ 𝜒 を導出し、TANK モデルの PE
曲線を描き、RANK モデルとの条件付き需要反応比を導出・比較するところまでを中心
に議論を展開します。Bilbiie 原論文の記号体系との対応、集計 Euler 方程式の動学、反転
領域の性質、数値例の代数計算、および確率的割引因子（SDF）を用いた再帰的消費関数の
厳密な導出は発展補論にまとめていますので、授業時間に余裕がある場合や自習用教材と
して活用してください。

2     表記と基本設定
2.1    用語

本講義で用いる主要なマクロ経済学用語を整理します。

      • New Keynesian（NK）モデル：価格硬直性のもとで、総需要の大きさが企業の産
       出量を決定する現代標準的な動学的一般均衡マクロ経済モデルの総称です。
      • RANK（Representative-Agent New Keynesian）モデル：すべての家計が
       同一であり、単一の代表的家計によって集計需要が決定される伝統的な NK モデル
       です。
      • TANK（Two-Agent New Keynesian）モデル：家計を「流動性制約家計」と「貯
       蓄家計」の 2 タイプに二分化した NK モデルです。
         – Type H 家計（hand-to-mouth consumers）：手元流動性制約に直面し、金
            融資産や株式を一切持たず、当期の現在所得をすべて消費する家計です。
         – Type S 家計（Ricardian savers）：金融市場で名目債券を取引し全企業の株
            式を保有して、異時点間の消費平準化を行う貯蓄家計です。

                                                 5
      • HANK（Heterogeneous-Agent New Keynesian）モデル：連続的な所得リス
        ク、借入制約、資産分布、予備的貯蓄行動などを精密に組み込んだより高度な異質家
        計 NK モデルです。本講義では TANK モデルまでに焦点を当て、HANK モデル固
        有の予備的貯蓄行動などは扱いません。
      • Planned Expenditure（PE）曲線：所与の実質利子率ギャップのもとで、民間部
        門の計画消費（計画支出）を経済全体の現在所得の関数として表した曲線です。政府
        支出が存在しない本モデルでは、計画支出は計画消費と完全に一致します。
      • Marginal Propensity to Consume（MPC）：限界消費性向。
      • Elasticity of Intertemporal Substitution（EIS）：異時点間代替弾力性。本講
        義ノートでは 𝛾 を異時点間代替の逆弾力性（相対的リスク回避度）として定義して
        いるため、EIS は 1/𝛾 となります。



2.2    環境と家計タイプ

本モデルにおいて、家計タイプ（Type H または Type S）は生涯を通じて外生的に固定さ
れており、両タイプは全く同一の選好構造（同一のパラメータ 𝛾, 𝜑）および同一の労働生産
性を持ちます。決定的な差異は、資産市場への参加機会と所得帰着の構造にあります。

      • Type H 家計：金融資産（名目債券）も株式も保有せず、毎期手元に入る実質労働所
        得と政府からの移転給付の全額を消費します。
      • Type S 家計：国内の全企業の株式を保有し、民間債券市場で無リスクの名目債券
        を取引します。債券は民間主体間で取引される純供給ゼロの資産であり、政府債務
        は存在しません。したがって、対称均衡においては Type S 家計全体の集計債券保
        有量もゼロとなりますが、個々の Type S 家計が直面する異時点間の債券選択から
        Euler 方程式が導出されます。

企業の集計純配当 𝑑𝑡 は、価格マークアップ是正補助金と企業一括税を相殺した後の配
当を定常消費水準で正規化した一次近似変数です。政府は Type H 家計に対して総額
𝜆𝑧𝑡 = 𝜏𝐷 𝑑𝑡 の移転給付を行い、その財源は全額 Type S 家計に対する一括税として調達
されます。したがって、純配当の残余である (1 − 𝜏𝐷 )𝑑𝑡 が株式保有者である Type S 家計
に帰属し、Type S 家計一人当たりの実質配当受取（移転負担控除後）は (1−𝜏𝐷 )𝑑𝑡 /(1−𝜆)
となります。パラメータ 𝜏𝐷 は、定常配当ゼロの周りでの一次近似上の負荷係数であり、定
常状態での水準配当の保有シェアそのものを表しているわけではありません。

第 7 回の講義では、代表的家計の Euler 方程式、Rotemberg 型価格調整費用、およびテイ
ラー・ルールを連立させ、標準的な RANK モデルの 3 本の NK 方程式体系を導出しまし

第 12 回において、あえて NK フィリップス曲線やテイラー・ルールを前面に出さず、実質
利子率ギャップ 𝑟̃𝑡 を所与として計画消費の現在所得反応を分析する理由はどこにあるの
でしょうか。期待閉鎖係数 𝑝 も、外生的な確率過程ではなく簡約形の閉鎖係数として設定
されています。したがって、本講義が導き出すのは「所与の実質利子率経路に対する条件付
きの総需要反応」であり、インフレ率と名目金利が内生的に同時決定される完全均衡の政策
インパルス応答ではありません。

これこそが、Bilbiie（2020）が提唱した New Keynesian Cross の分析手法です。PE

曲線と 45 度線の交点によって均衡所得が決定されるという学部マクロ初級の幾何学的図

 1. 直接効果の担い手：誰が実質利子率ギャップに直接反応して消費を変化させるの

代表的家計モデル（RANK）では、単一の家計が完全な金融市場を通じて異時点間の消費平

ただし、TANK モデルが常に RANK モデルよりも大きな総需要反応を示すとは限りま

体の 1 − 𝜆 へと減少するためです。TANK モデルにおける総需要効果の大きさは、「直
接効果の縮小（1 − 𝜆 倍）」と「所得フィードバックの増幅（乗数の拡大）」のどちらの力が
勝るかによって決定されます。

13.4 講義全体を貫く 3 つの見方
本講義を通じて、受講生の皆さんが習得したマクロ経済学的な視座は、以下の 3 つの対立
軸に集約されます。

  1. 現在所得と将来所得の峻別：学部マクロの素朴な消費関数では現在所得のみが消費
      を決定していました。これに対し、動学的最適化の世界では家計は生涯にわたる将来
      所得を見据えて消費を平準化します。そのため、代表的家計モデルでは現在所得フィ
      ードバックはほぼ消滅します。しかし TANK モデルでは、手元流動性制約家計の存
      在によって、学部マクロで学んだ現在所得フィードバックが現代的装いのもとで鮮
      やかに復活します。
  2. 相対価格と数量調整の峻別： 古典派・RBC の世界では価格と賃金が瞬時に伸縮調
      整し、経済の産出量は供給側の生産性や労働選好によって決定されます。一方、ニュ
      ーケインジアンの世界では名目価格が硬直的であるため、中央銀行の金利政策が実
      質利子率を動かし、総需要が企業の数量調整（産出量）を主導します。RBC モデルで
      求めた産出量は、NK モデルにおいて「需給ギャップを測るための自然産出量」とい
      う基準値として活かされています。
  3. 集計量と所得分配の峻別：代表的家計（RANK）モデルでは、単一の家計が労働所得、
      配当所得、資産利息のすべてをプールして受け取るため、
                               「誰が所得を受け取ってい
      るか」という分配問題は集計需要に一切現れませんでした。これに対し、TANK モ

                             35
   デルでは家計タイプ間で限界消費性向（MPC）が異なるため、同一のマクロ集計所得
   であっても、それが賃金・配当・移転のいずれとして誰に分配されるかによって、総
   需要の大きさが決定的に左右されます。第 12 回の 𝜒 は、まさにこの分配チャネルの
   力を 1 つのパラメータに凝縮したものです。

13.6 今後の発展

本講義で修得した基礎理論から先へと広がる現代マクロ経済学の最前線は、大きく 3 つの
フロンティアに分類されます。

  1. 家計および所得分配の精緻化（HANK モデルへの展開）： TANK モデルの 2 タ
    イプ構造を超えて、連続的な所得リスク、借入制約、非流動的資産（住宅・株式）と
    流動的資産（預金・現金）を併せ持つ多資産 HANK （Heterogeneous-Agent New
    Keynesian）モデルへと拡張する方向です。また、名目賃金硬直性を導入することで、
    賃金調整の遅れが不平等や総需要に与える影響を追究します。
  2. 需要項の拡張と財政政策の分析（資本蓄積と DSGE モデル）：本講義では設備投資
    を捨象しましたが、民間投資 𝐼𝑡 や政府購入 𝐺𝑡 を導入することで、財市場均衡は水
    準で 𝑌𝑡 = 𝐶𝑡 + 𝐼𝑡 + 𝐺𝑡 となります。実質利子率は消費のみならず企業の資本蓄
    積にも直接作用します。

 INFO 資本を含む RBC モデルと DSGE の数値解法

 成長理論では長期の資本蓄積を扱いますが、確率的ショックのもとで資本ストックを
 内生的に蓄積する RBC モデルや DSGE モデルでは、水準の資本蓄積方程式

                        𝐾𝑡+1 = (1 − 𝛿)𝐾𝑡 + 𝐼𝑡

 が新たな内生的状態変数を作り出します。資本ストック 𝐾𝑡 は過去から引き継がれる
 所定状態変数（predetermined state variable）となるため、前向きのジャンプ変数（消
 費やインフレ率）と連立させて解く必要があり、単一のショックに比例する解を予想
 する未定係数法だけでは解けなくなります。
 この課題を克服するため、定常状態の周りで対数線形化した連立合理的期待体系を行
 列形式で表現し、Blanchard–Kahn 条件によって解の存在と一意性を判定したうえ
 で、generalized Schur（QZ）分解を用いて policy function と transition law を数値
 的に計算する手法が標準的に用いられます。本講義で学んだ動学理論は、まさにこの
 数値解法（Klein, 2000 等）へと直結しています。


  3. 非線形動学と実証データとの結合：名目金利のゼロ下限制約（ZLB）や大規模ショッ
    クのもとでは、一次近似の線形モデルでは捉えきれない強い非線形性が発現します。

実質利子率ギャップの上昇が集計消費を抑制するという通常の負の傾きを持つためには、
