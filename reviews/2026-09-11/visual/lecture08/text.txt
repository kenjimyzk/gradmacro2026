1   講義の目的
本講義では、代表的家計をもつニューケインジアン・モデルの標準体系である RANK
（Representative Agent New Keynesian：代表的家計ニューケインジアン）モデルの



                           1
一般化と、各種マクロ経済ショックに対する動学的反応を学びます。

本講義の具体的な学習目標は、以下の 4 点です。

  1. 第 3 回から第 7 回にかけて導出してきた各主体の理論的部品を統合し、完成された
    RANK モデルとして体系化する。
  2. 第 7 回で扱った簡略化ケース（線形生産技術 𝛼 = 0、政府支出なし）を、固定資本シ
    ェア 𝛼 > 0（労働に関する収穫逓減）と外生的な政府支出を含む一般形へと拡張す
    る。
  3. 一般化された環境のもとで「自然産出量」、
                        「自然利子率」
                              、および「需給ギャップ（産
    出ギャップ）」を厳密に定義・導出する。
  4. 導出された 3 本のニューケインジアン方程式を用いて、金融政策ショック・技術シ
    ョック・政府支出ショックという 3 つの異なる外生ショックがマクロ経済に与える
    影響を比較・検討する。

本回で扱う RANK モデルは、柔軟価格の実物ブロックに「Dixit–Stiglitz 型の独占的競
 「Rotemberg 型の価格硬直性（価格調整費用）」および「中央銀行の金融政策ルール（テ
争」
イラー・ルール）」を統合した、現代マクロ経済学における代表的な動学的確率的一般均衡
（DSGE）モデルです。なお、固定資本ストックは外生的に所与（𝐾̄ = 1）とし、投資や資本
蓄積は導入しません。この簡略化により、資本蓄積に伴う複雑な動学を一旦捨象し、自然水
準の決定メカニズムと金融政策の伝達経路という本質的な論点に集中することができま
す。この RANK モデルの確固たる理解は、後続の講義で学ぶ TANK（Two-Agent New
Keynesian）や HANK（Heterogeneous Agent New Keynesian）といった、家計の
異質性を取り入れたフロンティア・モデルを学ぶための不可欠な土台となります。



1.1 本回の位置づけ

DSGE モデルの標準的な構築・分析プロセスは、通常以下の 3 段階で進められます。第 3
回から第 7 回にかけて、私たちはこのプロセスの基盤となる個々の部品（家計の異時点間
選択、企業の独占的価格設定、価格調整費用、政策ルール）を順を追って導出してきました。
本第 8 回では、これらを一つに統合し、完成された RANK モデルとして動学的な振る舞い
を読み解くことに専念します。

  1. 家計・企業・政府の動学的最適化問題を定式化し、それぞれの一階条件を導出する。

  2. 集計条件および市場均衡条件（財市場、労働市場、債券市場）を連立させ、経済全体の
   一般均衡体系を導出する。
  3. 非線形な均衡体系をゼロインフレ定常状態の周りで対数線形化し、状態空間表現や
   インパルス応答関数（IRF）を用いてショックの伝達メカニズムを分析する。

快な Rotemberg 型の二次価格調整費用を採用します。

       が過熱状態にあるのか停滞状態にあるのかを判断することはできません。
      3. テイラー原則の決定的一意性：テイラー原則（𝜙 > 1）は、インフレ率の上昇に対して
       名目利子率をそれ以上に引き上げることで実質利子率を高め、前向きな期待体系に
       おいて合理的期待均衡の安定性と一意性を担保します。
      4. モデルの簡略化と分析の限界：本モデルは代表的家計、所与の固定資本、投資の捨象
       という仮定を置いているため、家計間の富の異質性、流動性制約、所得分配効果、およ
       び設備投資の動学などは考慮されていません。



6.2    まとめ

第 8 回では、資本分配率 𝛼 > 0 と政府支出 𝐺𝑌 > 0 を含む一般化された RANK モデル
を構築し、動学的 IS 曲線、NK フィリップス曲線、およびテイラー・ルールからなる 3 本
の方程式体系へと集約しました。各ショックは、自然産出量と自然利子率をそれぞれ異なる
メカニズムと方向へ動かします。その結果、同じ金融政策ルールの下にあっても、金融緩和、
技術進歩、政府支出は、需給ギャップやインフレ率に対して対照的なマクロ経済反応をもた
らすことが明らかになりました。

ここまでは金融政策ルールを外生的に所与として均衡を解いてきましたが、第 9 回では政
策ルールそのものを評価対象とし、社会厚生を最大化する最適政策のあり方を探究します。
さらにその後の講義では、代表的家計の仮定を緩めた TANK や HANK へと分析を拡張
していきます。
