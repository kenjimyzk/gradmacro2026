基本問題

問 1 [Core] [Derivation]：消費配分と横断性条件
2 期間問題のオイラー方程式は
                                 1        1
                                    = 𝛽𝑅
                                 𝐶𝑡      𝐶𝑡+1

です。したがって、
                                   𝐶𝑡+1
                                        = 𝛽𝑅
                                    𝐶𝑡

を得ます。𝛽𝑅 > 1 なら消費は増加し、𝛽𝑅 < 1 なら減少します。

無限期間の追問では 𝛽𝑅 = 1 なので、オイラー方程式は一定消費を要求します。一定消費 𝐶 のもと
で予算制約を反復すると、

                  𝐵𝑁     𝑅
              lim   𝑁
                      =     [𝑌 + (𝑅 − 1)𝐵−1 − 𝐶] = 26(1.2 − 𝐶)
              𝑁→∞ 𝑅     𝑅−1
です。各候補を代入すると次のようになります。

              一定消費 𝐶       lim 𝐵𝑁 /𝑅𝑁     No-Ponzi 条件     横断性条件

                     1.1           2.6    満たす             満たさない
                     1.2             0    満たす             満たす
                     1.3          -2.6    満たさない           満たさない



対数効用では横断性条件の左辺は (1/𝐶) lim 𝐵𝑁 /𝑅𝑁 なので、両条件を満たすのは 𝐶 = 1.2 です。
この経路では 𝐵𝑡 = 5 が続きます。
                   資産水準は正でも、その割引現在価値はゼロへ収束します。



問 2 [Core] [Derivation]：借入制約
𝐵𝑡 = 𝐵 で制約がバインドすると、貯蓄を限界的に増やす方向だけが実行可能です。その方向の効用

                           −𝑢′ (𝐶𝑡 ) + 𝛽𝑅𝑢′ (𝐶𝑡+1 ) ≤ 0

                              𝑢′ (𝐶𝑡 ) ≥ 𝛽𝑅𝑢′ (𝐶𝑡+1 )

あります。
